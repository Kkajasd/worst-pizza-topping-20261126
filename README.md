## What it does

`main.ts` (Node.js stdlib only) writes a single funny line — under 200
characters — pitching a genuinely terrible pizza topping to
`/output/entry.txt`. The line sells the topping like a real menu item, with
a surprising turn: a single wet sock, toasted just enough to be legally
food, served with a straight face and no refund.

## Run

```sh
node main.ts
cat /output/entry.txt
```
